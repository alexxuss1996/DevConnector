# DevConnector

- TypeScript strict mode, prefer simple solutions
- Run `pnpm run lint` and `pnpm run build` before committing
- React/Next.js: keep components small, colocate types
- Never delete, overwrite, truncate, or "clean up" a `.env` file, and never run
  a command that would (`rm`, `git clean`, `mv`, a formatter over the repo).
  Secrets live at `~/.secrets/*.env` (mode 600) and the in-repo `.env` paths are
  symlinks to them, so a deleted symlink is recoverable — restore the link, do
  not recreate the file with placeholder values
- If an env var is missing, read `~/.secrets/` or ask; never invent a value and
  never write a guessed value into a `.env`
